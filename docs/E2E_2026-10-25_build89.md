# KuranApp 1.1.3 (89)

Expanded voice commands in Turkish, English and Dutch: last-read position, page/juz/verse navigation, playback pause/resume/stop/next/replay, verse translation, bookmarks, text size/zoom, day/night theme, fullscreen and command help. Long press a microphone for help and optional typed commands using the same parser.

Surah repetition accepts the requested Turkish oku/seslendir/dinlet/cal verbs and numeric or spoken repeat counts. Repeating a whole surah sequences all its verses for each round; whole-chapter recordings use the same repeat queue. The displayed remaining count excludes the currently playing round. Pausing preserves playback position and repetition state.
