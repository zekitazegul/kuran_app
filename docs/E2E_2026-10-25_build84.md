# KuranApp 1.1.3 (84)

## Change

- Original vector adaptations of Islamic minbar star lattice, girih, rumi/palmette and mosque tile ornament. References: MOTIF_REFERENCES.md.
- Separate Samarkand, Bukhara and Tashkent motifs, with regional color palettes and distinct geometry/floral ornament.
- Default ornament intensity raised from 0.07 to 0.18. Versioned migration increases previously faint patterns; subsequent explicit user preferences remain respected. Intensity range: 0.04 to 0.40.
- Large motif previews in a responsive gallery. Background and popup selections stay independent.
- Feature tutorial revision 2: existing users see only the new motif step; Settings can replay the full tutorial.
- Only the newly added motif choices appear in this build's tr/en/nl release notes.
