# Public release candidate 1.1.2+78

The user-visible version advances from the previous public 1.1.1 release to
1.1.2. The internal build is 78. This supersedes the phone-tested intermediate
builds 73–77; none of those intermediate builds was publicly released.

The release includes the explicit MP3 extractor fixing the Samsung Beyyine 98:3
failure, eight corrected audio catalog entries, persistent verse selection with
two adjustable handles, compact memorization fields, mandatory discovered updates,
and the explained final installer-removal step. The installer is 1.3 (build 4).
No separate installer is required for subsequent in-app updates.

Validation:

- Full Flutter regression suite: 223 tests passed. Dart analysis: no issues.
- Silent download/hash/decode audit: all 31,180 recordings passed, with 6,236
  verses for each of five complete reciters. Details are in the build 76 report.
- Beyyine completed all eight verses on the Wi-Fi phone after the extractor fix.
- Selection handles and memorization fields were verified on the phone, with
  widget coverage at phone/tablet portrait and landscape sizes in tr/en/nl.
- Updated completion wording was verified on the phone in English and Turkish;
  all three native locale resource sets match. Saved-language update notes passed
  their three regression tests.
- The final 1.1.2 APK installed successfully over Wi-Fi on the user's SM-S926B.
  The phone showed "Yenilikler · 1.1.2" and package inspection confirmed
  versionCode 78, versionName 1.1.2.
- Release preparation verified that the embedded installer matches the standalone
  installer and that no MP3 recordings are bundled in the main APK.

Release target: `v1.1.2-78`. Main APK: 85,891,407 bytes, SHA-256
`d5e12ae267f307ef3b83f8f0267e80bec9a1f239ebb2ae4150cbffbe9362509a`.
Public release notes describe the features added since the previous public build
72 in Turkish, English and Dutch. Older clients obtain this version from Settings
> Updates; startup update enforcement applies once they run 1.1.2.
