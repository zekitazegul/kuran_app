# KuranApp 1.1.3 (85)

- All decorative background/popup motifs and the dashboard ornament removed. The reading card also uses one solid color.
- Independent solid background/menu choices: cream, white, sage, sky, lavender, sand; matching dark-mode surfaces. Legacy motif selections migrate to cream/white without changing navigation choices.
- Removed menu pin buttons and reorder-handle icons. Long press the shortcut itself and drag vertically to reorder, or drop onto the bottom navigation to create a copy. Existing duplicate and five-shortcut checks remain.
- Bottom + visible only at zero or one shortcut; hidden at two or more. Default three-shortcut layout keeps Home centered.
- Tutorial and release notes synchronized in tr/en/nl; feature tutorial revision 3 teaches the solid color picker.

Validation: 25 focused tests passed (build/test85-final.log), including real long-press gestures, cross-area transfers, color selection/persistence, plus boundary, and phone/tablet portrait/landscape layouts in all interface locales. Static analysis clean (build/analyze85-final.log).
